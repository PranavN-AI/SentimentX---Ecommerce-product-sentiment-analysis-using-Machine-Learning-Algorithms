# SentimentX - The Sentiment Analysis using Machine Learning

Upload a CSV of product reviews. SentimentX labels each review as positive, neutral or negative, shows where it sits on a sentiment scale, lists the words behind the verdicts, and lets you download the reviews (CSV) or the full report (JSON).

## Run it

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open http://127.0.0.1:8000. The model is already trained (`artifacts/`). If it's missing, the app trains it on first start.

## Train on your own data

Put a CSV with a `review` (or `text`) column and a `sentiment` (or `label`) column, using positive, neutral or negative, then run:

```bash
python train.py --data path/to/your_reviews.csv
```

This rebuilds `artifacts/model.joblib` and `artifacts/metrics.json`. Real labelled data such as Amazon, Flipkart or IMDb reviews will give the most reliable results.

To regenerate the bundled corpus: `python make_dataset.py` then `python train.py`.

## About the bundled data

`data/reviews_large.csv` (45,000 reviews) is generated by `make_dataset.py`, not collected from real customers. It uses phrase templates with negation, intensifiers, mixed sentences, typos, and 6% label noise. Its metrics are a useful sanity check, but accuracy on real reviews will be lower.

## How it works

1. Each review becomes word features (1 and 2 word phrases) and character features (2 to 5 letter pieces, which handle misspellings).
2. A multinomial Logistic Regression assigns probabilities to the three classes. The confidence is the highest probability, and the score is P(positive) minus P(negative).
3. Metrics come from a 15% test split the model never trained on.
